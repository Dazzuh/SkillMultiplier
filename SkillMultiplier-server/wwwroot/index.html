SkillMultiplier

Per-action skill experience multipliers — SPT 4.1

Carry over the previous version's settings?

This version tunes individual actions where the old one tuned whole skills, and the maths behind the gains changed with it — so nothing is carried over on its own. What each old value becomes is listed under Upgrading in the readme; a carried skill lands on every one of its actions at once.

Unsaved changes
Global multiplier live, no restart

One number on top of every row: at 2.00 each row pays double whatever it says. Applied by the game client the moment you press Apply — no restart. Crafting and Hideout Management are server-side skills the client never sees, so the global does not reach them; their own rows below do (after a restart).

Advanced config — server-side duplicates

These rows scale a skill from the server's globals while the same skill also has client-side rows above — and the two multiply together, so 2.00 here and 2.00 there pays 4.00 in game, not 2.00. They also need a game restart, where the client rows apply live. They are kept out of the way so a per-skill or global change cannot set both sides by accident; the group sliders above only touch the live rows. Crafting and Hideout Management stay in the main list: the client never applies multipliers to those two skills, so their server rows are the only lever, not a duplicate.

Not tunable and why

Skills with no experience to multiply at all — checked against the server's globals and against the actions the game client builds. They are missing from the list above on purpose: a slider that did nothing would be worse than no slider, so the reason is listed instead.

    Everything above is applied by the game client, while it is running — including the fatigue switch. Values that live in the server's globals take effect at the next client start, so the Apply message says when a restart is still needed. A save reaches a running game over its socket, even mid-raid — and it only affects future XP: points already earned are untouched.

    Base values come either from the server's live globals or, for the actions that only exist inside the game client, from what the game has actually granted — the rows say which. Every description was read from the game's own trigger condition for that action rather than guessed from a field's name. No fatigue removes the decay that makes each point of a session worth 0.6× the one before it once you pass two points; it keeps the 1.3× bonus on a session's first point.
