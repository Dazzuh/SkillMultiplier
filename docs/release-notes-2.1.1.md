# SkillMultiplier 2.1.1

Everything that did nothing in 2.1.0 does now.

## Changes

**Action rows apply in raids.** 2.1.0 matched them by the action object, so they only worked in the hideout.

**Server-paid XP is scaled.** Repairs, crafting and hideout XP. Their rows did nothing before.

**The hideout gym has a row.** Random strength or endurance per rep. Its popup tells the truth now.

**The crafting cycle row** no longer misdescribes itself.

## Worth knowing

A 10x row reads as about 4x on the skill page above level 9. It is still a real 10x against vanilla.

Row changes land immediately, even mid-raid. `Settings.*` rows want a game relaunch.

## Installing

Unzip into your SPT root so the plugin lands in `BepInEx/plugins/` and the module in
`SPT_Runtime/user/mods/dazzuh-skillmultiplier/`, then restart `SPT.Server.exe`. Saved multipliers and keys are
unchanged.
